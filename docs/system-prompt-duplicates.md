# 英文系统提示词重复检测报告

对 `content/system_prompts/en/` 下全部 630 个英文正文做近重复检测，得到 0 个重复组，涉及 0 个正文文件。

## 判定方法

- 分词：词级 3-gram shingle（保留标点无关的词序列）
- 候选召回：MinHash(64 排列) + LSH 分桶
- 精确比对：对候选对计算 Jaccard 相似度与包含度
- 判定阈值：Jaccard ≥ 0.85 记为「近乎相同」；包含度 ≥ 0.95 记为「一方内容几乎完全包含另一方」
- 最小重叠量：50 个 shingle，滤掉短文本的偶然重合

只比较英文正文：中文文件是同一条目的译文，比对中文只会重复报告同样的分组。

## 使用说明

站点在构建期自动计算重复组，无需手工维护：

- 每条重复正文在列表里带 `DUP-xxxx` 标记；
- 打开详情抽屉可看到同组条目、相似度 / 包含度，并可直接跳转到同组其他条目；
- 列表上方的「隐藏重复条目」开关只保留每个重复组中最完整的一条。
