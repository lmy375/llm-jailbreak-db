# 数据来源

本数据库收录的越狱提示词均来自以下公开来源，每条记录在 `jailbreak_prompts.yaml` 中的 `source_url` 字段指向其具体出处，`source_id` 引用对应的数据来源大库。表格由 `jailbreak_prompts.yaml` 顶层的 `source` 数据自动生成；`索引时间` 为数据入库日期，`Commit` 为索引时使用的版本，非 GitHub 来源不适用。
