创建新体验

Roblox Studio 是一款免费应用程序，可在 Windows 和 macOS 上使用，是制作 Roblox 体验的基本构建工具。

在 Studio 打开的状态下，在 Windows 上按 CtrlN 或在 macOS 上按 ⌘N 来创建一个新的 location（场地）。或者，你也可以点击 All Templates 标签页下的 Baseplate 模板。

Baseplate 模板由一个出生点组成，玩家角色在进入该体验时会出现在世界中的该位置，此外还有一块宽敞开放的 baseplate 地板。

UI 与 UX

大多数 Roblox 用户使用移动设备游玩，因此以移动设备为先来设计你的用户界面（UI）和用户体验（UX）是明智的。如果你想迎合 Xbox 或 PC/Mac 用户，请把常用操作绑定到手柄的快捷键和键盘上的特定按键。

更多信息，请参阅 Input and Camera

所有 Roblox 体验都共享少数几个核心 UI 元素，例如聊天和玩家列表。定期测试你自己的 UI，确保不会与它们在屏幕上的位置冲突，或者把你不想显示的内容禁用掉。许多体验都使用相似的 UI 模式，例如在屏幕底部设置物品栏槽位。复用这些模式将确保经验丰富的 Roblox 用户能凭直觉理解如何使用你的界面。

尽可能使用一致的图标，并让一切尽可能地可视化。许多年轻用户难以阅读文字密集的界面，而且无论能力如何，许多年轻用户都更排斥阅读。可视化的 UI 也更容易为国际受众做本地化。

Toolbox

[Toolbox]/projects/assets/toolbox) 包含你已发布的全部模型、图片、网格模型、音频等资源，也包含你所属群组发布的资源。它还包含一部分由 Roblox 或 Roblox 社区成员制作的资源。

Part 插入

Part 按钮会向 workspace 中插入一个新部件。点击该按钮上的小下拉箭头，可以选择 Block、Sphere、Wedge、Corner Wedge 或 Cylinder。更多信息，请参阅 Parts。

UI 设计器

UI 按钮会打开一个标签页，让你可以快速插入、调整大小和重新定位常见的屏幕 UI 对象，例如标签、框架和按钮。关于 UI 标签页中可用对象的详细信息，请参阅 UI。

导入 3D
