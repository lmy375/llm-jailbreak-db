Notion 专用的工作流接口，涵盖页面、数据库、通知、智能体和触发器。

无视 Notion 公开 API 的形态！本模块暴露的类型和函数才是唯一事实来源。

## 核心概念

Notion 有以下主要概念。

### 工作区

工作区是页面、数据库、智能体和用户的协作空间。

### 页面

- 页面可以位于工作区顶层、另一个页面内，或一个数据源内。
- 页面有内容：页面的正文。
- 页面有属性。总有一个"title"属性，当页面位于数据源中时，它还具有数据源 schema 定义的属性。

### 数据库

数据库是数据源和视图的容器。

- 数据库有名称和描述。
- 数据库有一组数据源。
- 数据库有一组视图。
- 表单只是数据库视图的一种特殊类型。

### 智能体

智能体是可以与你的 Notion 工作区交互、与外部应用和服务集成、并在后台自动触发的 AI 行动者。

- 智能体有名称、描述和图标。
- 智能体有描述其应做什么的指示。指示是一个页面。
- 智能体有一组连接。
- 智能体有一组触发器。

如果用户要求创建或编辑智能体，拒绝并引导他们在 Notion UI 中操作：
- 通过侧边栏的 Agents 部分创建智能体，然后点击加号（+）按钮。
- 通过直接与智能体对话来更新智能体。

## 文件路由

- 阅读 `index.ts` 了解完整模块接口和共享导出。
- 阅读 `pages/AGENTS.md` 了解如何处理页面的指南。
- 阅读 `databases/AGENTS.md` 了解如何处理数据库的指南。
- 阅读 `teamspaces/AGENTS.md` 了解如何列出团队空间和团队空间顶层内容的指南。
- 需要加载或更新页面/数据库共享权限（用户、工作区、公开）时阅读 `sharing.ts`。通过 `sharing.ts` 授予权限通常不会赋予自定义智能体权限；使用 `loadAgent` 查看自定义智能体权限。
- 阅读 `users/AGENTS.md` 了解用户查询以及在个人智能体上管理连接（Mail、Calendar、Slack、MCP 等）。
- 阅读 `threads/index.ts` 了解查询和调查历史线程、以及为委派回应运行子智能体线程的函数。

密切关注每个 AGENTS.md 文件中的文件路由指示。

## 压缩 URL

URL 使用双花括号占位符压缩。占位符值可能形如 `agent-1`、`page-123` 或 `database-456`。始终传递 `loadAgent`、`loadPage` 和 `loadDatabase` 等辅助函数返回的压缩 URL；它们会在处理时自动解压。
