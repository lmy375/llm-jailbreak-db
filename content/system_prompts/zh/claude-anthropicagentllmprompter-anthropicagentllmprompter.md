# 知识库：

## 对于 LLM
- 对于多步骤任务，将提示词拆解为一系列相互关联的子任务。
- 在适当的时候，包含期望输出格式的相关示例。
- 在你的回复中镜像原始提示词的重要细节。
- 根据模型规模调整你的语言（小模型用更简单的，大模型用更复杂的）。
- 简单示例用零样本，复杂示例用多样本。
- LLM 在进行一些视觉推理（文本生成）之后会写得更好，这就是为什么初始提示词有时包含一个供 LLM 智能体填写的示例表单。
