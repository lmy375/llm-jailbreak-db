像 `var _p_x = this.x` 这样在函数内提前取出 this 并在函数作用域内使用的方式，叫什么？


在 JavaScript 中，像 `var _p_x = this.x` 这样在函数内部先把 this 保存到变量中再使用的这种方式，通常被称为"缓存 this"或 **"this 绑定存储"**。英文一般说是 "caching this" 或 **"storing this"**。

这种方式主要用于函数内部 this 的上下文有可能发生变化的情况，例如在回调函数或事件处理器中，以保持 this 的原始值。一般在以下情形下有用：

javascript

복사
function MyObject() {
  this.x = 10;
  var self = this; // 把 this 缓存到 self
  this.someMethod = function() {
    console.log(self.x); // self 始终引用原来的 this
  };
}
这种模式经常使用 self、_this、that 这样的变量名，借此可以避免 this 的动态绑定带来的问题。自 ES6 之后，由于箭头函数（arrow function）会在词法作用域中获取 this，这类模式的必要性有所减少，但在特定情况下它仍然是有效的方式。



请推荐一些像缓存 this 这样的模式


除了在 JavaScript 中缓存 this 的模式之外，还有一些经常用于提高代码稳定性和可读性、或解决特定问题的模式。下面是在与 this 缓存相似的语境下有用的模式。每个模式都能在特定情况下提高代码的可预测性或优化性能。

1. 缓存 this（Caching this）
说明：在函数内部把 this 的上下文保存到变量中，以确保在回调函数或嵌套作用域中引用原来的 this。
用途：在 this 会动态变化的情况下使用（例如：事件处理器、回调、setTimeout）。
示例：
javascript

복사
function MyObject() {
  this.value = 42;
  var self = this; // 缓存 this
  setTimeout(function() {
    console.log(self.value); // 访问原来 this 的 value
  }, 1000);
}
变体：使用 self、_this、that 这样的变量名。其中 self 最常见。
替代方案：ES6 箭头函数会在词法作用域中获取 this，因此很多时候不需要缓存。
javascript

복사
setTimeout(() => console.log(this.value), 1000); // 使用箭头函数
2. 方法绑定（Method Binding）
说明：使用 Function.prototype.bind 把函数的 this 固定到特定对象上。
用途：把函数作为回调或事件处理器传递时，防止 this 被意外改变。
示例：
javascript

복사
function MyObject() {
  this.value = 42;
  this.print = function() {
    console.log(this.value);
  };
  // 用 bind 固定 this
  document.addEventListener('click', this.print.bind(this));
}
优点：显式设置 this，代码直观。
缺点：bind 会创建新的函数，因此内存占用可能略有增加。
替代方案：可以用箭头函数实现类似效果。
javascript

복사
document.addEventListener('click', () => this.print());
3. 利用闭包做变量缓存（Variable Caching）
说明：把重复计算或 DOM 访问这类开销较大的操作结果保存到变量中以供复用。
用途：性能优化，在 DOM 操作或循环中尤其有用。
示例：
javascript

복사
function optimizeQuery() {
  var element = document.getElementById('myElement'); // 缓存 DOM
  return function() {
    element.style.display = 'block'; // 使用缓存的 DOM 元素
  };
}
变体：保存到对象属性或外部变量中。
javascript

복사
var cache = {};
function getData(key) {
  if (!cache[key]) {
    cache[key] = expensiveOperation(key); // 缓存结果
  }
  return cache[key];
}
优点：减少不必要的运算或 DOM 访问，提升性能。
4. 记忆化（Memoization）
说明：缓存函数结果，使得对相同输入不必重复计算。
用途：对计算开销大的函数（例如：斐波那契、递归调用）进行性能优化。
示例：
javascript

복사
function memoize(fn) {
  var cache = {};
  return function(arg) {
    if (arg in cache) return cache[arg];
    return (cache[arg] = fn(arg));
  };
}
var fib = memoize(function(n) {
  return n < 2 ? n : fib(n - 1) + fib(n - 2);
});
console.log(fib(10)); // 通过缓存快速计算
优点：避免重复计算，大幅提升性能。
缺点：可能增加内存占用。
5. 事件委托（Event Delegation）
说明：不在各个元素上分别绑定事件处理器，而是在父元素上设置一个处理器来委托处理事件。
用途：高效管理事件处理器，尤其适用于动态添加的元素或大量元素。
示例：
javascript

복사
document.getElementById('parent').addEventListener('click', function(e) {
  if (e.target.matches('.child')) {
    console.log('Child clicked:', e.target);
  }
});
优点：减少内存占用，自动适用于动态元素。
类似模式：与缓存 this 结合使用，以保持父对象的上下文。
javascript

복사
function MyList() {
  var self = this;
  this.value = 42;
  document.getElementById('parent').addEventListener('click', function(e) {
    if (e.target.matches('.child')) {
      console.log(self.value); // 使用缓存的 this
    }
  });
}
6. 使用 IIFE 进行作用域隔离（Immediately Invoked Function Expression）
说明：使用立即执行函数（IIFE）把变量或 this 保护在特定作用域内。
用途：防止污染全局作用域，封装初始化代码。
示例：
javascript

복사
(function() {
  var self = this; // 把 this 缓存到 IIFE 作用域中
  console.log(self === window); // true（浏览器环境）
})();
优点：防止变量冲突，对一次性初始化很有用。
变体：与模块模式结合。
javascript

복사
var MyModule = (function() {
  var self = this;
  return {
    getValue: function() {
      return self.value;
    }
  };
})();
