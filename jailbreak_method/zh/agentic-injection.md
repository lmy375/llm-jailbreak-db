# 智能体、记忆与工具层注入

**Agentic, Memory & Tool-Layer Injection** · 攻击族 ID `agentic-injection`

## 核心原理

当 LLM 被赋予工具调用、长期记忆、仓库文件读写、多模态输入等能力后，攻击面从"单轮提示词"扩展到**整个智能体运行时**。攻击者不再局限于当前对话，而是把恶意指令**持久化**到智能体会反复读取的位置。

典型载体：

- **工具 / MCP 投毒**：在被调用的外部工具或 MCP 服务返回的数据中夹带指令；
- **记忆注入**：把指令写入智能体的长期记忆中，使其在后续会话中持续生效；
- **仓库文件劫持（Agent File Hijacking）**：把恶意指令写入 `AGENTS.md`、`README` 或项目文件，诱导编码型智能体执行（NIST 已记录 AGENTS.md 注入分类法）；
- **多模态向量**：将指令隐藏在图片、元数据或文档的不可见层中。

## 被利用的缺陷

- **信任边界扩张**：智能体把工具输出、文件内容、记忆条目当作可信指令来源。
- **持久化放大**：一次成功的注入会在后续多次交互中反复触发。

## 相关提示词

覆盖 `LJB-25`、`LJB-31`、`LJB-40`、`LJB-49` 等条目。

## 防御视角

- 明确区分"数据"与"指令"：工具返回、文件内容、记忆条目一律视为不可信数据。
- 对写入记忆 / 仓库文件的内容做来源与内容审计。
- 高危操作（执行、外发、删除）需**独立的人工/策略确认**，不因上下文文本而绕过。
